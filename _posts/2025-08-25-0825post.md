## **🏛️ 서비스 개요**

Barlow는 국회 의안 정보를 실시간으로 추적하고 구독할 수 있는 모바일 애플리케이션입니다. 사용자가
관심 있는 법안과 의원을 구독하여 최신 입법 활동을 놓치지 않도록 도와주는 정치 정보 서비스입니다.

## **🎯 핵심 가치**
- 실시간 의안 추적: 국회 의안 정보 API를 통한 최신 법안 정보 제공
- 맞춤형 구독 서비스: 관심 의원/정당/법안 카테고리별 구독 및 알림
- 간편한 모바일 접근: 복잡한 국회 정보를 쉽게 소비할 수 있는 UX
- AI 요약 기능: 복잡한 법안 내용을 AI로 요약하여 제공

## **📱 주요 기능**

### **1. 사용자 관리 (Account Management)**
- 회원가입/로그인: 소셜 로그인 또는 게스트 모드
- 디바이스 관리: 다중 디바이스 지원 및 푸시 토큰 관리
- 회원 탈퇴: 개인정보 완전 삭제 처리

### **2. 홈 대시보드 (Home Dashboard)**
- 오늘의 법안: 당일 처리되는 주요 법안 썸네일
- 내 구독 현황: 구독 중인 의원/정당의 최신 활동
- 알림 센터: 맞춤형 알림 메시지 관리

### **3. 의안 정보 시스템 (Bill Information)**
- 의안 목록 조회: 필터링, 정렬, 페이징 지원
- 의안 상세 정보: 제안자, 진행 상태, 상세 내용
- 사전 예고 법안: 입법 예고된 법안 정보
- 최근 처리 법안: 통과/부결된 최신 법안

### **4. 구독 관리 (Subscription Management)**
- 의원별 구독: 특정 국회의원의 발의 법안 추적
- 정당별 구독: 정당별 입법 활동 모니터링
- 법안 카테고리별 구독: 관심 분야별 법안 추적
- 알림 설정: 구독별 세부 알림 설정

## **5. 알림 시스템 (Notification System)**
- 실시간 푸시 알림: 구독 기반 맞춤형 알림
- 알림 센터: 과거 알림 이력 관리
- 알림 설정: 주제별 알림 on/off 설정

## **🎨 디자이너를 위한 UI/UX 가이드**

## **화면 구성**

### **1. 홈 화면**
- 오늘의 주요 법안 카드 (이미지 썸네일)
- 내 구독 현황 요약
- 최신 알림 배지

### **2. 의안 목록 화면**
- 필터 옵션 (진행상태, 제안자 유형, 날짜)
- 무한 스크롤 리스트
- 각 의안별 요약 카드

### **3. 의안 상세 화면**
- 의안 기본 정보 (제목, 제안자, 진행상태)
- AI 요약 섹션
- 상세 내용 확장/축소
- 관련 의원 구독 버튼

### **4. 구독 관리 화면**
- 구독 중인 의원/정당 리스트
- 각 구독별 알림 설정
- 구독 해지 기능

### **5. 알림 센터**
- 시간순 알림 리스트
- 읽음/안읽음 상태 표시
- 알림별 액션 버튼

**데이터 흐름**

- 실시간성: 국회 API → 배치 처리 → 푸시 알림
- 개인화: 사용자 구독 정보 → 맞춤형 콘텐츠 필터링
- 접근성: 복잡한 정치 정보 → 간단한 요약 형태로 변환

## **📊 비즈니스 메트릭**
- 사용자 참여도: DAU/MAU, 구독 수, 알림 반응률
- 콘텐츠 소비: 의안 조회수, 상세 페이지 체류 시간
- 구독 패턴: 인기 의원/정당, 구독 유지율
- 기술 성능: API 응답시간, 배치 처리 성공률

## **🎯 서비스 핵심**
- 국회 의안 실시간 추적 모바일 앱의 백엔드
- 관심 의원/정당 구독으로 맞춤형 정치 정보 제공
- AI 요약 기능으로 복잡한 법안을 쉽게 이해

## **📱 주요 화면 구성**
1. 홈: 오늘의 주요 법안, 내 구독 현황, 알림 센터
2. 의안 목록: 필터링 가능한 법안 리스트 (무한스크롤)
3. 의안 상세: 기본정보 + AI요약 + 관련 의원 구독
4. 구독 관리: 의원/정당 구독 리스트, 알림 설정
5. 알림 센터: 시간순 알림, 읽음 상태, 액션 버튼

## **🎨 디자인 포인트**
- 정치 정보의 단순화: 복잡한 국회 데이터를 직관적으로
- 개인화 경험: 사용자별 구독 기반 맞춤 콘텐츠
- 실시간성 강조: 최신 의안 정보의 즉시성
- 접근성: 정치에 관심 없던 사용자도 쉽게 이해
